A3.1 – Pointer Operations

Aim

To understand pointer arithmetic and pointer operations using an integer array containing the stock of eight blood groups.

1. Given Statement

int stock[8];
int *p = stock;

Here:

- "stock[8]" is an integer array containing eight stock values.
- "p" is a pointer to an integer.
- "p = stock" stores the address of the first array element in p.

2. Explanation of Pointer Operations

a) p + 3

It moves the pointer three integer positions forward.

It points to "stock[3]".

b) *(p + 3)

It accesses the value stored at the fourth array position.

It is equivalent to "stock[3]".

c) p[3]

It accesses the fourth element of the array.

It is equivalent to "*(p + 3)".

d) *p++

It accesses the value currently pointed to by p and then moves the pointer to the next integer position.

It is equivalent to "*(p++)".

Important: The pointer moves after accessing the current value.

3. Example

Assume the stock array contains:

int stock[8] = {10, 20, 30, 40, 50, 60, 70, 80};
int *p = stock;

Expression| Result
p + 3| Address of stock[3]
*(p + 3)| 40
p[3]| 40
*p++| 10, then p points to stock[1]

4. Memory Diagram

Assume the starting address is 1000 and each integer occupies 4 bytes.

1000 → 1004 → 1008 → 1012 → 1016

After executing:

p = p + 3;

The pointer points to address 1012, which contains 40.

After executing:

*p++;

The current value 40 is accessed, and the pointer moves to the next element at address 1016.

5. Conclusion

Pointer arithmetic allows us to access array elements using memory addresses. The expressions "*(p + 3)" and "p[3]" access the same element. The expression "*p++" accesses the current value and then advances the pointer. These operations are useful for managing blood stock efficiently in C programs.
