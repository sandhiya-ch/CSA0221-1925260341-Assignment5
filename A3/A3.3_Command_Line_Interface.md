A3.3 – Command-Line Interface

Aim

To design a command-line interface for the District Blood Bank Network using argc and argv.

1. Meaning of argc and argv

- argc: Stores the number of command-line arguments.
- argv: Stores the command-line arguments as strings.
- argv[0]: Contains the program name.
- argv[1]: Contains the command.
- argv[2]: Contains the blood group.
- argv[3]: Contains the number of units, when required.

2. Command-Line Examples

Finding Donors

bloodbank find O+

This command finds donors belonging to blood group O+.

Issuing Blood

bloodbank issue A- 2

This command issues 2 units of A- blood.

3. Function Prototype

int main(int argc, char *argv[]);

4. Algorithmic Pseudocode

ALGORITHM MAIN(argc, argv)

BEGIN
    IF argc < 3 OR argc > 4 THEN
        DISPLAY "Invalid number of arguments"
        DISPLAY "Usage instructions"
        RETURN 1
    ENDIF

    command ← argv[1]
    bloodGroup ← argv[2]

    IF bloodGroup is invalid THEN
        DISPLAY "Invalid blood group"
        RETURN 1
    ENDIF

    IF command = "find" AND argc = 3 THEN
        FIND donors of bloodGroup

    ELSE IF command = "issue" AND argc = 4 THEN
        CHECK whether argv[3] is a valid positive integer
        IF valid THEN
            ISSUE the given number of units
        ELSE
            DISPLAY "Invalid units"
            RETURN 1
        ENDIF

    ELSE
        DISPLAY "Invalid command"
        RETURN 1
    ENDIF

    RETURN 0
END

5. Handling Invalid Arguments

Invalid Input| Error Message
No arguments| Missing command
Too many arguments| Too many arguments
Invalid blood group| Invalid blood group
Unknown command| Invalid command
Negative units| Invalid number of units
Non-numeric units| Units must be a number

The program displays an appropriate error message and stops safely instead of executing an invalid operation.

6. Alternative Concept – Returning an Index Instead of a Pointer

Instead of returning a pointer to the lowest-stock element, the function can return its array index.

Function Prototype

int findLowestStockIndex(const Stock stock[], int count);

Pseudocode

ALGORITHM FINDLOWESTSTOCKINDEX(stock, count)

BEGIN
    IF count = 0 THEN
        RETURN -1
    ENDIF

    lowest ← 0

    FOR i ← 1 TO count - 1 DO
        IF stock[i].units < stock[lowest].units THEN
            lowest ← i
        ENDIF
    ENDFOR

    RETURN lowest
END

Updating Using the Index

int index = findLowestStockIndex(stock, count);

if (index != -1) {
    stock[index].units = 20;
}

7. Complexity Analysis

Method| Time Complexity| Extra Space
Returning pointer| O(n)| O(1)
Returning index| O(n)| O(1)

Both methods search the entire array to find the lowest stock.

8. Comparison

Pointer Method| Index Method
Returns an address.| Returns an integer position.
Directly accesses the element.| Accesses the element using its index.
Pointer may become invalid after realloc.| Index can be reused after realloc if the element order is preserved and the index remains valid.
Requires pointer safety.| Avoids storing a potentially dangling pointer.

9. Conclusion

The command-line interface allows users to find donors and issue blood using argc and argv. Invalid arguments must be checked before performing operations. Returning an index instead of a pointer is a safer choice when the donor or stock array may be reallocated.
