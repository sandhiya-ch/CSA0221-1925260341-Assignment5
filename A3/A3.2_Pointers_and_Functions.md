A3.2 – Pointers and Functions

Aim

To design a function that finds the blood group with the lowest stock and returns a pointer to that element.

1. Structure Definition

typedef struct {
    char bloodGroup[4];
    int units;
} Stock;

2. Function Prototype

Stock *findLowestStock(Stock stock[], int count);

3. Algorithmic Pseudocode

ALGORITHM FINDLOWESTSTOCK(stock, count)

BEGIN
    IF count = 0 THEN
        RETURN NULL
    ENDIF

    lowest ← ADDRESS OF stock[0]

    FOR i ← 1 TO count - 1 DO
        IF stock[i].units < lowest.units THEN
            lowest ← ADDRESS OF stock[i]
        ENDIF
    ENDFOR

    RETURN lowest
END

4. Explanation

1. The function receives the stock array and its size.
2. It initially assumes the first element has the lowest stock.
3. It compares the units of all remaining blood groups.
4. If a smaller stock value is found, its address is stored.
5. Finally, the function returns the address of the blood group with the lowest stock.

5. Example

Blood Group| Available Units
A+| 40
B+| 25
O+| 10
AB+| 30

The lowest stock is O+ with 10 units.

6. Updating the Stock Using a Pointer

Stock *lowest = findLowestStock(stock, 4);

if (lowest != NULL) {
    lowest->units = 20;
}

The pointer directly accesses and updates the original stock element.

7. Why Returning a Pointer to a Local Variable Is Wrong

A local variable is created inside a function and its lifetime ends when the function returns.

If its address is returned:

- The pointer becomes dangling.
- The memory may be reused.
- Accessing it causes undefined behaviour.
- It may produce incorrect results or a program crash.

Therefore, the function should return a pointer to an existing array element instead of a local variable.

8. Complexity Analysis

Operation| Complexity
Finding lowest stock| O(n)
Returning pointer| O(1)
Extra space| O(1)

9. Conclusion

Pointers allow a function to return the address of an existing stock element. The caller can directly update the stock using the returned pointer. Returning a pointer to a local variable must be avoided because its lifetime ends when the function returns.
