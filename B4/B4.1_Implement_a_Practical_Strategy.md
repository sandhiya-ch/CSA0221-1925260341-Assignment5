B4.1 – Implement a Practical Strategy

1. Aim

To implement a growable donor list that loads donor records from a file, increases its capacity when required, and measures the memory used and time taken.

2. Growable Donor List

A growable donor list uses dynamic memory allocation. When the list becomes full, its capacity is doubled using "realloc()".

3. C Program – Complete TODO 1

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    int id;
    char group[4];
} Donor;

typedef struct {
    Donor *data;
    int size, capacity;
} DonorList;

int add_donor(DonorList *list, int id, const char *group)
{
    if (list->size == list->capacity) {
        int new_capacity = (list->capacity == 0)
                           ? 2 : list->capacity * 2;

        Donor *p = realloc(list->data,
                           new_capacity * sizeof(Donor));

        if (p == NULL)
            return 0;

        list->data = p;
        list->capacity = new_capacity;
    }

    list->data[list->size].id = id;

    strncpy(list->data[list->size].group, group, 3);
    list->data[list->size].group[3] = '\0';

    list->size++;
    return 1;
}

int main(void)
{
    DonorList list = {NULL, 0, 0};

    const char *groups[] = {"O+", "A+", "B-", "AB+", "O-"};

    for (int i = 0; i < 5; i++) {
        if (!add_donor(&list, 7001 + i, groups[i])) {
            printf("Memory allocation failed\n");
            free(list.data);
            return 1;
        }

        printf("added %d (%s): size = %d, capacity = %d\n",
               list.data[i].id,
               list.data[i].group,
               list.size,
               list.capacity);
    }

    free(list.data);
    return 0;
}

5. Memory and Time Analysis

- Initial capacity is 2 donors.

- When the list becomes full, capacity doubles.

- The capacities grow as 2, 4, 8, 16 and so on.

- The memory used by the allocated array is:
  
  "capacity × sizeof(Donor)"

- Adding a donor usually takes O(1) time.

- Adding n donors takes O(n) total time (amortized).

6. Why Is realloc() Stored in a Temporary Pointer?

The result of "realloc()" is stored in a temporary pointer named "p".

If "realloc()" fails, it returns "NULL" and the original memory block remains valid. Storing the result directly in "list->data" could lose the original pointer and cause a memory leak.

Therefore, a temporary pointer is safer.

8. Conclusion

The growable donor list automatically increases its capacity when more donors are added. Dynamic memory allocation avoids reserving a fixed-size array in advance. The temporary pointer makes "realloc()" safer, and the allocated memory is released using "free()".
