B4.2 – Check Memory Safety

1. Aim

To check whether the growable donor list releases all dynamically allocated memory and runs without memory errors.

2. Memory Allocation

The program uses "realloc()" to increase the donor list capacity.

Donor *p = realloc(list->data,
                   new_capacity * sizeof(Donor));

if (p == NULL)
    return 0;

list->data = p;
list->capacity = new_capacity;

3. Releasing Memory

After completing the program, allocated memory must be released using:

free(list.data);
list.data = NULL;

This prevents memory from remaining allocated after the program finishes.

4. Memory Safety Checks

The following checks are important:

1. Check whether "realloc()" returns NULL.
2. Store the result of "realloc()" in a temporary pointer.
3. Do not access memory outside the allocated array.
4. Call "free()" when the allocated memory is no longer needed.
5. Do not use the pointer after freeing it.

5. AddressSanitizer Test

Compile the program using:

gcc -Wall -Wextra -g -fsanitize=address -fno-omit-frame-pointer B4.1_Implement_a_Practical_Strategy.c -o donor_test
