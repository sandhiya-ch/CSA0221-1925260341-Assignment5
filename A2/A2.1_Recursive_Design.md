A2.1 – Recursive Design

Aim

To design recursive algorithms for calculating the digital root of a donor ID and calculating the power of a number (base^n).

1. Digital Root Using Recursion

A digital root is obtained by repeatedly adding the digits of a number until only one digit remains.

Example

9875 = 9 + 8 + 7 + 5 = 29

29 = 2 + 9 = 11

11 = 1 + 1 = 2

Digital Root = 2

Recursive Pseudocode

Algorithm 1: SUMDIGITS

ALGORITHM SUMDIGITS(n)

BEGIN
    IF n < 10 THEN
        RETURN n
    ENDIF

    RETURN (n MOD 10) + SUMDIGITS(n DIV 10)
END

Algorithm 2: DIGITALROOT

ALGORITHM DIGITALROOT(n)

BEGIN
    IF n < 10 THEN
        RETURN n
    ENDIF

    s ← SUMDIGITS(n)

    RETURN DIGITALROOT(s)
END

Base Case

If n is less than 10, return n. Recursion stops when only one digit remains.

Recursive Case

The digits are added using SUMDIGITS. The result is passed again to DIGITALROOT until a single digit is obtained.

2. Power Function Using Recursion

The power function calculates base raised to exponent n.

The formula is:

base^n = (base^(n/2))²

For odd exponents:

base^n = base × (base^(n/2))²

Recursive Pseudocode

ALGORITHM POWER(base, n)

BEGIN
    IF n = 0 THEN
        RETURN 1
    ENDIF

    half ← POWER(base, n DIV 2)

    IF n MOD 2 = 0 THEN
        RETURN half × half
    ELSE
        RETURN base × half × half
    ENDIF
END

Base Case

If n = 0, return 1 because any non-zero number raised to power zero is 1.

Recursive Case

The exponent is divided by 2. The smaller power is calculated recursively and multiplied by itself. If n is odd, it is also multiplied by the base.

3. Conclusion

Recursion is a technique in which a function calls itself to solve a problem. The digital root algorithm repeatedly adds digits, while the power algorithm uses the divide-and-conquer method. Both algorithms use base cases to stop recursion and recursive cases to solve smaller problems.
