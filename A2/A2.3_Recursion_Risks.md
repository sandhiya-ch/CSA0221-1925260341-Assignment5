A2.3 – Recursion Risks

Aim

To understand the risks of recursion and identify when a loop should be used instead.

1. What Happens If the Base Case Is Missing?

A base case is the stopping condition of a recursive function.

If the base case is missing:

- The function continues calling itself.
- The number of function calls increases continuously.
- The call stack uses more memory.
- The program may crash due to stack overflow.

Example

ALGORITHM COUNT(n)

BEGIN
    RETURN COUNT(n - 1)
END

This function has no base case. Therefore, it continues calling itself without stopping.

2. When Should Recursion Be Replaced by a Loop?

Recursion should be replaced by a loop when:

- The problem can be solved easily using repetition.
- A large number of recursive calls may occur.
- Stack memory should be saved.
- Better memory efficiency is required.

3. Alternative Concept – Digital Root Using a Loop

Instead of recursion, the digital root can be calculated using loops.

Pseudocode

ALGORITHM DIGITALROOT_LOOP(n)

BEGIN
    WHILE n >= 10 DO
        sum ← 0

        WHILE n > 0 DO
            sum ← sum + (n MOD 10)
            n ← n DIV 10
        ENDWHILE

        n ← sum
    ENDWHILE

    RETURN n
END

Example

Input: 9875

9875 → 29 → 11 → 2

Output: 2

4. Alternative Concept – Direct Formula

The digital root can also be calculated using the mathematical formula:

For n > 0:

Digital Root = 1 + (n - 1) MOD 9

For n = 0, the digital root is 0.

Example

n = 9875

Digital Root = 1 + (9875 - 1) MOD 9

Digital Root = 2

5. Complexity Analysis

Method| Time Complexity| Auxiliary Space
Recursive method| O(d)| O(d)
Loop method| O(d)| O(1)
Direct formula| O(1)| O(1)

Here, d represents the number of digits in the input number.

6. Comparison

Recursive Method:

- Uses function calls.
- Requires call stack memory.
- May cause stack overflow for deep recursion.

Loop Method:

- Uses repetition instead of function calls.
- Requires constant extra memory.
- Avoids recursion stack overflow.

Direct Formula:

- Calculates the result directly.
- Takes constant time.
- Uses constant extra memory.

7. Conclusion

A base case is necessary to stop recursion. Without it, the program may continue calling itself and cause stack overflow. For digital root calculation, the loop or direct formula is more memory-efficient than recursion. Therefore, loops are preferable when the problem can be solved through simple repetition.
