A4.1 – Growable Donor List

Aim

To design a dynamic donor list that starts with a small capacity and doubles its capacity using realloc() whenever the list becomes full.

1. Dynamic Memory Allocation

Dynamic memory allocation allows the program to allocate memory during execution according to the number of donors.

The following functions are used:

- malloc(): Allocates initial memory.
- realloc(): Increases or decreases allocated memory.
- free(): Releases allocated memory.

2. Donor Structure

typedef struct {
    int donorID;
    char name[50];
    char bloodGroup[4];
    int age;
    char phone[15];
    char lastDonationDate[15];
} Donor;

3. Initial Design

- Initial capacity = 2 donors.
- Current count = 0.
- When the list becomes full, capacity is doubled.
- realloc() is used to increase memory.

4. Algorithmic Pseudocode

Algorithm: INITIALIZE DONOR LIST

ALGORITHM INITIALIZE

BEGIN
    capacity ← 2
    count ← 0

    donors ← ALLOCATE MEMORY FOR 2 DONORS

    IF donors = NULL THEN
        DISPLAY "Memory allocation failed"
        RETURN FAILURE
    ENDIF

    RETURN SUCCESS
END

Algorithm: ADD DONOR

ALGORITHM ADDDONOR(donors, count, capacity, newDonor)

BEGIN
    IF count = capacity THEN

        newCapacity ← capacity × 2

        temp ← REALLOCATE donors TO newCapacity

        IF temp = NULL THEN
            DISPLAY "Memory allocation failed"
            RETURN FAILURE
        ENDIF

        donors ← temp
        capacity ← newCapacity

    ENDIF

    donors[count] ← newDonor

    count ← count + 1

    RETURN SUCCESS
END

5. Handling realloc() Failure

If realloc() fails:

1. It returns NULL.
2. The original memory block remains allocated.
3. The original pointer must not be overwritten.
4. The program displays an error message.
5. The new donor is not added.
6. The existing donor records are preserved.

Using a temporary pointer prevents losing the original memory address.

6. Complexity Analysis

Operation| Time Complexity
Adding a donor normally| O(1)
Resizing the list| O(n)
Adding n donors overall| O(n) amortized
Extra space| O(n)

7. Conclusion

A growable donor list uses dynamic memory allocation to store an unknown number of donors. Doubling the capacity using realloc() reduces frequent memory resizing. Using a temporary pointer protects existing data when memory allocation fails.
