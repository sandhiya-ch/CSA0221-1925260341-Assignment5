B1.1 – Validate the Implementation

1. Objective

To implement and test the digital root function, linear power function and halving power function.

2. C Program

#include <stdio.h>

int digitalRoot(int n) {
    if (n < 10)
        return n;
    return digitalRoot(n % 10 + digitalRoot(n / 10));
}

long long linearPower(int base, int n) {
    if (n == 0)
        return 1;
    return base * linearPower(base, n - 1);
}

long long halvingPower(int base, int n) {
    if (n == 0)
        return 1;

    long long half = halvingPower(base, n / 2);

    if (n % 2 == 0)
        return half * half;

    return base * half * half;
}

int main() {
    printf("Digital Root of 9875 = %d\n", digitalRoot(9875));
    printf("Digital Root of 0 = %d\n", digitalRoot(0));
    printf("Digital Root of 1 = %d\n", digitalRoot(1));

    printf("Linear Power 2^5 = %lld\n", linearPower(2, 5));
    printf("Linear Power 5^0 = %lld\n", linearPower(5, 0));

    printf("Halving Power 2^5 = %lld\n", halvingPower(2, 5));
    printf("Halving Power 5^1 = %lld\n", halvingPower(5, 1));

    return 0;
}

3. Expected Output

Digital Root of 9875 = 2
Digital Root of 0 = 0
Digital Root of 1 = 1
Linear Power 2^5 = 32
Linear Power 5^0 = 1
Halving Power 2^5 = 32
Halving Power 5^1 = 5

4. Test Explanation

Test| What it verifies
Digital root of 9875| Checks normal multi-digit input
Digital root of 0| Checks zero input
Digital root of 1| Checks single-digit input
Linear power 2^5| Checks normal exponent calculation
Linear power 5^0| Checks zero exponent
Halving power 2^5| Checks odd exponent calculation
Halving power 5^1| Checks base case and odd exponent

5. Result

All three recursive functions produced the expected results for ordinary values, zero and one. The implementation was successfully validated.
