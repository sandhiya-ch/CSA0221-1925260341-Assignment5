B1.2 – Compare with Your Design

1. Objective

To compare the implemented C functions with the pseudocode designed in Part A.

2. Comparison

Part A Pseudocode| C Implementation
SUMDIGITS and DIGITALROOT| Implemented using the recursive "digitalRoot()" function
Linear power algorithm| Implemented using "linearPower()"
Halving power algorithm| Implemented using "halvingPower()"
Base case for exponent zero| Implemented using "if (n == 0) return 1;"

3. Changes Made

1. Pseudocode statements were converted into C syntax.
2. The "digitalRoot()" function uses recursive calls to process the digits.
3. The linear power function reduces the exponent by one in each call.
4. The halving power function reduces the exponent by half to improve efficiency.
5. Return statements were used to send the calculated results back to the calling function.

4. Result

The C implementation follows the design prepared in Part A. Only programming syntax and variable declarations were adapted. The main algorithms and their logic remained the same.
