B1.4 – Find the Limit

1. Objective

To find the recursion limit of the linear power function and compare it with an iterative version.

2. C Program

#include <stdio.h>

long long power_linear(long long base, int exp) {
    if (exp == 0)
        return 1;

    return base * power_linear(base, exp - 1);
}

long long power_iterative(long long base, int exp) {
    long long result = 1;

    for (int i = 0; i < exp; i++) {
        result = result * base;
    }

    return result;
}

int main() {
    int n;

    printf("Enter exponent: ");
    scanf("%d", &n);

    printf("Linear recursive result: %lld\n", power_linear(1, n));
    printf("Iterative result: %lld\n", power_iterative(1, n));

    return 0;
}

3. Experimental Procedure

1. Run the program with a small exponent.
2. Gradually increase the exponent for the linear recursive function.
3. Continue testing until the program crashes due to stack overflow.
4. Record the largest value that completed successfully and the first value that caused a crash.
5. Test the iterative version with the same large exponent.

4. Observation Table

Method| Observation
Linear recursion| Uses a new function call for every exponent value
Iterative method| Uses a loop without recursive function calls
Large exponent| Linear recursion may crash due to stack overflow
Iterative method| Uses constant stack space

5. Explanation

Linear recursion creates many function calls. Each call uses stack memory. When the stack memory is exhausted, the program may crash due to stack overflow.

The iterative version uses a loop instead of recursive calls. Therefore, it does not create a large recursive call stack.

6. Complexity Analysis

Method| Time Complexity| Stack Space
Linear recursion| O(n)| O(n)
Iterative method| O(n)| O(1)

7. Result

Linear recursion uses more stack memory as the exponent increases. The iterative method avoids recursive stack growth and is more suitable for large exponents.
