B1.3 – Count the Calls

1. Objective

To count and compare the recursive calls made by linear power and halving power functions.

2. C Program

#include <stdio.h>

long long calls = 0;

long long power_linear(long long base, int exp) {
    calls++;

    if (exp == 0)
        return 1;

    return base * power_linear(base, exp - 1);
}

long long power_fast(long long base, int exp) {
    calls++;

    if (exp == 0)
        return 1;

    long long half = power_fast(base, exp / 2);

    if (exp % 2 == 0)
        return half * half;

    return base * half * half;
}

int main() {
    int values[] = {10, 100, 1000, 10000};

    printf("Exponent\tLinear Calls\tHalving Calls\n");

    for (int i = 0; i < 4; i++) {
        int n = values[i];

        calls = 0;
        power_linear(1, n);
        long long linear = calls;

        calls = 0;
        power_fast(1, n);
        long long fast = calls;

        printf("%d\t\t%lld\t\t%lld\n", n, linear, fast);
    }

    return 0;
}

3. Experimental Results

Exponent (n)| Linear Calls| Halving Calls
10| 11| 5
100| 101| 8
1,000| 1,001| 11
10,000| 10,001| 15

4. Comparison

- Linear recursion makes n + 1 calls because the exponent decreases by one each time.
- Halving recursion makes approximately log₂(n) + 1 calls because the exponent is divided by two.
- Halving recursion requires fewer calls for large values of n.

5. Complexity Analysis

Method| Time Complexity
Linear Power| O(n)
Halving Power| O(log n)

6. Result

The experiment shows that halving recursion is much faster than linear recursion in terms of recursive calls. As the exponent increases, the number of calls in linear recursion increases rapidly, while halving recursion increases slowly.
