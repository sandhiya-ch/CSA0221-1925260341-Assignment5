A1.1 – Identify the Functions

Aim

To divide the District Blood Bank Network program into smaller functions, where each function performs a specific task.

Functions and Their Purposes

Function| Purpose
registerDonor()| Registers a new donor.
checkEligibility()| Checks donor eligibility.
findDonors()| Finds donors of a particular blood group.
updateStock()| Updates available blood units.
issueBlood()| Issues blood to hospitals.
displayDonors()| Displays donor details.
saveDonors()| Saves donor details into a file.
loadDonors()| Loads donor details from a file.
saveStock()| Saves stock information.
loadStock()| Loads stock information.
displayMenu()| Displays the main menu.

Structure Chart

                 main()
                   |
    ---------------------------------
    |       |       |       |       |
 display  load   register check  find
  Menu   Donors  Donor   Eligibility Donors
                   |
    ---------------------------------
    |       |       |       |
 update  issue  display  save/load
 stock   blood  donors   files

Explanation

The main() function controls the entire program. It calls different functions to register donors, check eligibility, find donors, update blood stock and save or load records from files.

Conclusion

Functional decomposition makes the program easy to understand, develop, test and maintain.
