A1.3 – Return More Than One Value

Aim

To design a function that returns both the number of eligible donors and the ID of the youngest eligible donor.

1. Method 1 – Using Pointer Parameters

Function Prototype

int findEligibleDonors(
    const Donor donors[],
    int count,
    int *youngestID
);

Explanation

- The function returns the total number of eligible donors.
- The pointer "youngestID" stores the ID of the youngest eligible donor.
- The address is passed using "&" so the function can update the original variable.
- If no eligible donor is found, "youngestID" is set to -1.

Example

int youngest;
int total;

total = findEligibleDonors(donors, 5, &youngest);

printf("Eligible donors: %d\n", total);
printf("Youngest donor ID: %d\n", youngest);

2. Method 2 – Returning a Structure

Structure Definition

typedef struct {
    int eligibleCount;
    int youngestID;
} EligibilityResult;

Function Prototype

EligibilityResult findEligibleDonors(
    const Donor donors[],
    int count
);

Explanation

- A structure is used to store two results.
- "eligibleCount" stores the total number of eligible donors.
- "youngestID" stores the ID of the youngest eligible donor.
- Both values are returned together as one structure.
- If no eligible donor is found, "youngestID" is set to -1.

Example

EligibilityResult result;

result = findEligibleDonors(donors, 5);

printf("Eligible donors: %d\n", result.eligibleCount);
printf("Youngest donor ID: %d\n", result.youngestID);

3. Comparison of Both Methods

Pointer Method| Structure Method
Uses pointer parameters.| Uses a structure.
Returns count directly.| Returns both values together.
Caller provides an address.| Caller receives one structure.
Suitable for simple outputs.| Suitable for multiple related outputs.
Requires careful pointer handling.| Keeps results organized.

4. Alternative Concept – Using Global Variables

Global variables can be declared outside all functions and accessed by different functions.

Example

int eligibleCount = 0;
int youngestID = -1;

void findEligibleDonors(void)
{
    // Check donors and update global variables.
}

Explanation

In this method, functions share information through global variables instead of receiving data through parameters and pointers.

5. Complexity Analysis

Let n be the total number of donor records.

Operation| Time Complexity
Checking all donors| O(n)
Finding the youngest donor| O(n)
Storing the results| O(1)

Space Complexity: O(1) auxiliary space for both methods, excluding the donor array.

Using global variables does not change the running time or the overall memory requirement significantly.

6. Comparison with Global Variables

Parameter Method| Global Variable Method
Less coupling.| More coupling.
Easy to test.| Difficult to test.
Easy to reuse.| Less reusable.
Data is passed clearly.| Data is shared globally.
Better data control.| Accidental modification is possible.

7. Conclusion

Both pointer parameters and structures can return multiple values from a function. The structure method is better for returning related information because it keeps the results together. Using function parameters is better than global variables because it improves modularity, testing and reusability.
