A1.2 – Design the Interfaces

Aim

To design function prototypes for the District Blood Bank Network and decide whether parameters should be passed by value or by pointer.

1. Structure Definitions

typedef struct {
    int id;
    char name[50];
    char bloodGroup[4];
    int age;
    char phone[15];
    char lastDonationDate[15];
} Donor;

typedef struct {
    char bloodGroup[4];
    int units;
} Stock;

void displayMenu(void);

              size_t *count,

3. Parameter-Passing Decisions

Parameter| Method| Reason
Donor *donor| Pointer| To modify donor details.
const Donor *donor| Const pointer| To read donor details without changing them.
const Donor donors[]| Array/pointer| To access donor records without modifying them.
size_t count| Value| To pass the number of records.
size_t *count| Pointer| To update the number of records.
const char *bloodGroup| Const pointer| To read the blood group safely.
Stock *stock| Pointer| To update blood stock directly.
int units| Value| To pass the number of units.
const char *filename| Const pointer| To read the filename without modifying it.

4. Explanation

Pass by Value:

A copy of the variable is passed to the function. Changes made inside the function do not affect the original variable.

Pass by Pointer:

The address of the variable is passed. Changes made through the pointer can affect the original variable.

Use of Const Pointer:

The const keyword prevents the function from accidentally modifying the data through that pointer.

5. Conclusion

Function prototypes define how functions communicate with each other. Pointers help modify original data, while const pointers protect data from unwanted changes. Proper parameter passing makes the program modular, safe and reusable.
