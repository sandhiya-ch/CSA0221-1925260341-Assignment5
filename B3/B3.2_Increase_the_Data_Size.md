B3.2 – Increase the Data Size

1. Objective

To measure the file size and the time required to write and read donor records in text and binary formats.

2. Test Data Sizes

The following three data sizes are used:

- 1,000 donor records
- 10,000 donor records
- 100,000 donor records

3. Experimental Procedure

1. Generate the required number of donor records.
2. Write all records into a text file using fprintf().
3. Measure the time taken to write the text file.
4. Read all records using fscanf() and measure the reading time.
5. Repeat the same process using a binary file with fwrite() and fread().
6. Record the file sizes and execution times.

5. Analysis

- Text files store records in readable character format.
- Binary files store records in the form of bytes.
- Binary files are generally more compact for fixed-size structures.
- Text files are easier for humans to read and edit.
- Actual file sizes and execution times depend on the record structure and computer.

6. Result

The experiment compares text and binary file storage for increasing numbers of donor records. The measured file sizes and execution times will help identify the more suitable format for the application.
